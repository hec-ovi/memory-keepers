Track: The Collaborative Partner

Track askStatusWhere it lives
Interactive expert that guides, asks, and remembers Covered Each keeper is an expert on one life layer. Ask is grounded in opened books. Ridge keepers ask one real question. Monument routes across shelves.
Gets better every time it is used Covered Every tell writes or grows a book. Sleep binds leftover conversation. Nightly dreaming builds the graph and births ridge keepers from what keeps returning. Unattended.

Judging criteria (1 to 5 per criterion, bonuses lift the final to 6)

CriterionWeightHow the work answers it
Innovation and operational utility 40% Memories scatter across life. The product is not a chatbot: keepers write books, answers are grounded, night builds a knowledge graph and names what you avoid. Dreaming is the high-value action that runs without hand-holding.
Architectural discipline and tech stack 30% Boxes with contracts. ADK AgentTool, not transfer, so the root can synthesize. Firestore owns libraries and sessions (worlds, keepers, books, session, dreams). Dreaming is a Pub/Sub delivery run in-request and retried by the subscription. Runs are bounded (12 model calls, stop on a repeated call), every flow has a deterministic fallback. Meters, caps, island key, deploy token, billing detach.
Demo and production readiness 30% Hosted Cloud Run URL. README spin-up from zero and docker compose locally. This architecture diagram. Contract tests on the real FastAPI app and ADK runner. Video must still show Console, Vertex logs, and the .run URL.
