# Changelog

1.0: the whole game runs on one machine. Qwen3.6-35B-A3B on an OpenAI-compatible llama.cpp server writes every reply (fake tier for tests), through a lean in-house tool-calling loop: a run is at most 12 model calls, stops on a repeated call, and writes once more without tools carrying its lookups. One SQLite file holds every world. Dreams run on the engine's loop: asked from the HUD, dispatched by a tired keeper, and swept nightly at `DREAM_AT`. Keepers route each message to tell, ask or talk; passing remarks land in each keeper's notes book; resolve_date turns relative days into calendar dates; lookups (podcasts, songs, lyrics, books, films) are offered per kind of work named. The ridge keepers converse across every village shelf; the dreaming births only human themes. Worlds travel as one JSON file; samples/hector-island.json is the author's island, importable in one click.
